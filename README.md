**🚗 Ride Pooling System**

A simple desktop-based Ride Pooling System developed using Python, Tkinter, and MySQL.
The system allows users to offer rides, find available rides, and request to join rides.

📌 Features
* User Login and Registration
* Offer a Ride
* Find a Ride
* Search rides by route
* Send Ride Requests
* View My Requests
* Manage Ride Requests
* Accept or Reject Requests
* Logout and Back Navigation

**🧠 Data Structures Used**

| Data Structure  | Used For                       |
| --------------- | ------------------------------ |
| **Array**       | Store search results           |
| **Linked List** | Store and validate route stops |
| **Stack**       | Screen navigation              |
| **Queue**       | Manage ride requests           |
| **Tree**        | Route matching                 |

**🛠️ Technologies Used
* Python
* Tkinter – GUI
* MySQL – Database
* Data Structures & Algorithms
